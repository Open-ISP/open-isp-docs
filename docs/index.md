# Open-ISP documentation

## Introduction

Open-ISP provides modellers with an open-source capacity expansion modelling
capability base on the methodology and assumptions used by the Australian Energy Market
Operator's (AEMO) [Integrated System Plan](https://aemo.com.au/en/energy-systems/major-publications/integrated-system-plan-isp/2024-integrated-system-plan-isp).

## Core functionalities and workflow

The core functionalities of Open-ISP data handling and modelling tools form a set
sequential steps, which together allow the user to run ISP style capacity expansion
models. The core functionalities are:
